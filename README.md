# Rix7

Portal inmobiliario para Chile 🇨🇱 — construido con código abierto y capas gratuitas.

**En producción:** [rix7.vercel.app](https://rix7.vercel.app) · **Código:** [jatf71-a11y/rix7](https://github.com/jatf71-a11y/rix7) · Última versión: [v10.0.0](https://github.com/jatf71-a11y/rix7/releases/tag/v10.0.0)

## Qué es

Búsqueda con mapa GIS, velociómetros de precio y demanda, favoritos y alertas por correo, y una landing compartible hecha para WhatsApp que protege la dirección exacta.

## Stack

`Next.js 14` · `TypeScript` · `Tailwind CSS` · `Supabase (PostGIS)` · `MapLibre GL` · `Vercel`
